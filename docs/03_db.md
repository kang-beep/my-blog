# 03. Database (Supabase)

## 스키마 운영 방식

- Supabase에서 기존 `public` 테이블을 비운 뒤 **아래 DDL을 한 번 실행**해 고정 스키마로 맞춘다.
- 과거 문서에 있던 `ALTER`로만 FK를 거는 블록은 **구 DB에 기능을 덧붙일 때** 쓰던 것이며, 통째로 갈아엎는 경우 불필요하다.

## 관계

```
categories (1) ──< posts (N)
posts (1) ──────< comments (N)
profiles        (프로필·단일 행 등 운영 방식은 앱과 맞출 것)
portfolio_projects
```

## DDL (고정 스키마 · 한 번에 적용)

```sql
create extension if not exists pgcrypto;

create table public.categories (
  id uuid primary key default gen_random_uuid(),
  name text not null unique,
  slug text not null unique,
  sort_order int not null default 0,
  is_visible boolean not null default true,
  created_at timestamptz not null default now()
);
create index idx_categories_sort on public.categories(sort_order);

create table public.posts (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  slug text unique,
  excerpt text,
  status text not null default 'published',
  published_at timestamptz,
  content text not null,
  category text not null,
  category_id uuid references public.categories(id),
  tags text[] not null default '{}',
  image_url text,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create unique index idx_posts_slug_unique on public.posts(slug) where slug is not null;
create index idx_posts_created_at on public.posts(created_at desc);
create index idx_posts_category on public.posts(category);
create index idx_posts_tags_gin on public.posts using gin(tags);

create table public.comments (
  id uuid primary key default gen_random_uuid(),
  post_id uuid not null references public.posts(id) on delete cascade,
  nickname text not null,
  content text not null,
  created_at timestamptz not null default now()
);
create index idx_comments_post_id on public.comments(post_id);

create table public.profiles (
  id uuid primary key default gen_random_uuid(),
  display_name text,
  headline text,
  bio text,
  avatar_url text,
  github_url text,
  email text,
  updated_at timestamptz not null default now()
);

create table public.portfolio_projects (
  id uuid primary key default gen_random_uuid(),
  title text not null,
  slug text not null unique,
  summary text,
  content text,
  tech_stack text[] not null default '{}',
  repo_url text,
  demo_url text,
  image_url text,
  featured boolean not null default false,
  sort_order int not null default 0,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now()
);
create index idx_portfolio_sort on public.portfolio_projects(sort_order desc);
```

## GRANT + RLS

RLS만 켜고 `GRANT`가 없으면 `42501 permission denied` 발생.

### posts / comments

```sql
grant usage on schema public to anon, authenticated, service_role;

grant select on table public.posts to anon, authenticated, service_role;
grant select, insert on table public.comments to anon, authenticated;
grant insert, update, delete on table public.posts to authenticated, service_role;
grant delete on table public.comments to authenticated, service_role;

alter table public.posts enable row level security;
alter table public.comments enable row level security;

drop policy if exists "posts_select_public" on public.posts;
create policy "posts_select_public" on public.posts for select to anon, authenticated using (true);

drop policy if exists "comments_select_public" on public.comments;
create policy "comments_select_public" on public.comments for select to anon, authenticated using (true);

drop policy if exists "comments_insert_public" on public.comments;
create policy "comments_insert_public" on public.comments for insert to anon, authenticated with check (true);
```

글 **작성/수정/삭제**: `authenticated`용 정책 추가 (예: `auth.role() = 'authenticated'` 등).

### categories / profiles / portfolio_projects

```sql
grant select on table public.categories to anon, authenticated;
grant insert, update, delete on table public.categories to authenticated;
grant select on table public.profiles to anon, authenticated;
grant insert, update on table public.profiles to authenticated;
grant select on table public.portfolio_projects to anon, authenticated;
grant insert, update, delete on table public.portfolio_projects to authenticated;

alter table public.categories enable row level security;
alter table public.profiles enable row level security;
alter table public.portfolio_projects enable row level security;

drop policy if exists "categories_select_public" on public.categories;
create policy "categories_select_public" on public.categories for select to anon, authenticated using (is_visible = true);
drop policy if exists "profiles_select_public" on public.profiles;
create policy "profiles_select_public" on public.profiles for select to anon, authenticated using (true);
drop policy if exists "portfolio_select_public" on public.portfolio_projects;
create policy "portfolio_select_public" on public.portfolio_projects for select to anon, authenticated using (true);
```

**위 스니펫이 의미하는 것**

| 구분 | 내용 |
|---|---|
| `grant ... to authenticated` | **관리자 한정 아님.** Supabase Auth로 **로그인한 모든 사용자**(`authenticated` 역할). 회원가입을 막고 계정이 하나뿐이면 실무상 관리자만 로그인 가능하지만, DB 입장에선 “관리자” 플래그가 있는 게 아님. |
| INSERT / UPDATE / DELETE | 위 블록에는 **SELECT 정책만** 있음. RLS가 켜진 테이블에서 해당 명령용 **policy가 없으면 그 명령은 거부**된다. 즉 이 예시만 두면 `authenticated`가 INSERT·UPDATE·DELETE를 할 수 있게 **열어두지 않은 상태**에 가깝다. |
| 관리자만 쓰기 허용 | RLS에 예: `auth.uid() = '<관리자 user uuid>'` 조건의 INSERT/UPDATE/DELETE 정책을 **별도로** 추가해야 한다. |

쓰기 정책은 위 표 기준으로 설계해 추가할 것.

## 태그 쿼리 (참고)

```sql
select * from posts where 'React' = any(tags) order by created_at desc;

select tag, count(*) from posts, unnest(tags) as tag group by tag order by count desc;

select a.tag as t1, b.tag as t2, count(*) as w
from posts, unnest(tags) a(tag), unnest(tags) b(tag)
where a.tag < b.tag group by t1, t2 order by w desc;
```

## 트러블슈팅

| 증상 | 조치 |
|---|---|
| `schema cache` / 테이블 없음 | DDL 실행 후 재시도 |
| `permission denied` / 42501 | `grant usage on schema public`, 테이블 `GRANT`, RLS 정책 확인 |
| Actions ping 실패 | `service_role`에 `posts` SELECT 부여 |
| 클라이언트 환경변수 누락 | `.env.local` / Vercel `VITE_*` 확인 |
| SPA 직링크 404 | `vercel.json` 리라이트 확인 |
