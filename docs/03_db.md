## 테이블 요약

`schema.md`와 동일. 핵심만:

### `posts`

- `like_count` (int, default 0) — `post_likes` 트리거로 동기화
- `excerpt` nullable — `null`이면 프론트에서 본문 기반 자동 미리보기
- `image_url` — 목록 썸네일 전용 (상세 hero 미사용)
- `category` NOT NULL — 에디터에서 미선택 시 **`기타`** 로 자동 저장 (`DEFAULT_POST_CATEGORY_NAME`)
- `category_id` FK → `categories` (nullable이지만 앱은 `기타` id와 함께 저장)

### `post_likes`

- `post_id` FK → `posts` **ON DELETE CASCADE**
- `visitor_key` — 브라우저 `localStorage` UUID
- UNIQUE `(post_id, visitor_key)`

### `tag_stats` / `tag_edges`

- 관리자 글 create / update / delete 후 `refreshTagStats()`로 전체 재집계

### 카테고리 삭제

- `deleteCategory`: 해당 글은 **`기타`** 로 이동 (글 삭제 없음)
- **`기타` 카테고리는 삭제 불가**

### 글 삭제

- 앱: Storage → Giscus Edge Function → `posts` DELETE
- DB: `post_likes`는 CASCADE로 자동 삭제
- 상세: `docs/06_post_delete_and_giscus.md`

## GRANT + RLS

RLS만 켜고 `GRANT`가 없으면 `42501 permission denied` 발생.

한 번에 적용: **`docs/sql/authenticated_full_access_rls.sql`**

> 참고: 위 SQL에 `comments` 정책 블록이 남아 있을 수 있다. `comments` 테이블을 이미 drop했다면 해당 블록은 실행 시 무시되거나, drop policy만 남겨 두어도 된다.

### posts

```sql
grant select on table public.posts to anon, authenticated, service_role;
grant insert, update, delete on table public.posts to authenticated, service_role;
-- RLS: posts_select_public, posts_*_authenticated (authenticated_full_access_rls.sql)
```

### post_likes

```sql
-- migrate_post_likes.sql 참고
-- anon/authenticated: select, insert, delete (익명 좋아요·취소)
```

### 외부 피드 테이블

- anon/authenticated: **SELECT only**
- INSERT/DELETE: GitHub Actions (`service_role`)

## 트러블슈팅

| 증상 | 조치 |
|------|------|
| `schema cache` / 테이블 없음 | DDL·마이그레이션 실행 후 재시도 |
| `permission denied` / 42501 | `grant usage on schema public`, 테이블 `GRANT`, RLS 정책 확인 |
| `new row violates row-level security` | `authenticated_full_access_rls.sql` 실행 |
| `refresh_tag_stats` 실패 | `migrate_fix_refresh_tag_stats_delete.sql` |
| Actions ping 실패 | `service_role`에 `posts` SELECT 부여 |
| 글 삭제 후 이미지·댓글 잔존 | `docs/06_post_delete_and_giscus.md` |
| 클라이언트 환경변수 누락 | `.env.local` / Vercel `VITE_*` 확인 |
| SPA 직링크 404 | `vercel.json` 리라이트 확인 |
